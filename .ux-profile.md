# UX profile (Yang Ming Indonesia registration portal)

Dibuat dengan default karena repo belum dikonfigurasi. Edit langsung bila perlu.

- Aesthetic reference: Stripe (clear, restrained, 1px borders, soft shadows)
- Accessibility target: WCAG 2.1 AA (text 4.5:1, borders/controls 3:1, hit target 44x44)
- Brand tone: Utilitarian & Minimal, sentence case, verb-first buttons
- Icon library: none (text only, no emoji as UI icons). Pick Lucide if icons are needed later.
- Accent: one green hue (#15803d). Neutrals carry everything else.
- Type: Inter, weights 400/500/600 only; sizes 12 / 14 / 16 and a Minor Third scale for headings.
- Motion: 150 / 200 / 300 ms, ease-out in, ease-in out, transform + opacity only.

## Banned
Glassmorphism, rainbow/multi-hue gradients, decorative gradients, cartoon empty states,
pastel pills around static metadata, icons inside inputs (except password toggle / search).
